# Checklist: antes de abrir una Pull Request

- [ ] La rama está actualizada respecto a la rama base (sin conflictos pendientes).
- [ ] El diff completo fue revisado — no solo el último commit.
- [ ] No hay cambios no relacionados con el propósito de la PR.
- [ ] Hay tests para el comportamiento nuevo o corregido.
- [ ] Los tests corren en verde localmente (no asumido, verificado).
- [ ] El título y la descripción explican qué cambia y por qué, no solo "fix" o "update".
- [ ] Se referencia el ticket relacionado, si existe.
- [ ] Se usó el confirmación explícita del usuario antes de crear la PR (ver [`rules/git-conventions.md`](../rules/git-conventions.md)).
